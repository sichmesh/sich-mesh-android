# SICH Mesh для Android

Застосунок для Android до пристроїв мережі **SICH** ([sichmesh.org](https://sichmesh.org)).
(Застосунок для iPhone буде окремим проєктом, `sich-mesh-ios`.)

Версія 0.1:

- знаходить пристрій SICH через Bluetooth LE і парується з ним за 6-значним кодом з екрана пристрою;
- показує стан пристрою (ОРЛИК, LoRa, GPS, прошивка);
- передає **ОРЛИК** (анонімний чат через інтернет) через телефон, коли в пристрою немає Wi-Fi:
  телефон пересилає на сервер і назад запечатані кадри однакового розміру. Він не бачить ні
  повідомлень, ні контактів, ні ключів: вони лишаються на пристрої;
- працює з вимкненим екраном (фонова служба зі сповіщенням) і сам перепідключається.

Решта можливостей пристрою (чат ОРЛИК, чат LoRa, вузли, карта, налаштування) додаватиметься поступово.

Застосунок використовує лише Android SDK: усередині не працює жодна стороння бібліотека.

## Як він говорить з пристроєм

Bluetooth LE, один GATT-сервіс, повідомлення поділені на шматки: див. `docs/phone-link.md` у прошивці SICH.
Застосунок викликає той самий API, що й вебпанель пристрою. `link/Chunks.kt` працює за тими самими
правилами, що й код пристрою; `app/src/test/resources/vectors.txt` містить шматки, зроблені кодом
пристрою, і тести перевіряють застосунок на них.

## Збірка

JDK 17 і Android SDK (обидва є в Android Studio).

```sh
./gradlew testDebugUnitTest      # тести
./gradlew assembleRelease        # app/build/outputs/apk/release/app-release.apk
```

GitHub Actions збирає такий самий APK після кожного push (`.github/workflows/build.yml`). Поки що він
підписаний налагоджувальним ключем: лише для перевірки. Офіційні випуски підписуватимуться ключем SICH;
його відбиток буде опубліковано на sichmesh.org, щоб кожен міг перевірити, що APK справжній. Сам ключ
ніколи не потрапляє в цей репозиторій.
